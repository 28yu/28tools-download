# tips 記事用スクリーンショットの置き場

`tips/*.html` の記事に貼る画像はここに置きます。
（`images/screenshots/` はアドインのマニュアル用。用途が違うので混ぜないこと）

## ディレクトリ構成

記事1本につきフォルダ1つ。フォルダ名は記事のファイル名（拡張子なし）と揃えます。

```
images/tips/
├── README.md                          ← このファイル（サイトには配信されない）
├── revit-cloud-model-recovery/        ← tips/revit-cloud-model-recovery.html 用
│   ├── 01-fatal-error-dialog.png
│   ├── 02-save-recovery-file.png
│   └── ...
└── <次の記事のスラッグ>/
    └── 01-....png
```

## ファイル名の付け方

`<2桁の連番>-<内容を表す英小文字とハイフン>.png`

- 連番は**記事に出てくる順**。間に足したくなったら `02a-...` ではなく、
  全体を振り直すより `05-` `06-` と末尾に足していくほうが楽（順序は HTML 側で決まるため）
- 日本語ファイル名は使わない（URL エンコードで扱いづらくなる）
- 拡張子は `.png`（UI のスクリーンショットは PNG が劣化しない）

## 画像の仕様

| 項目 | 目安 |
|---|---|
| 横幅 | 1200〜1600px（等倍。記事側で自動縮小される） |
| 容量 | 1枚 300KB 以下。超えるなら TinyPNG 等で圧縮 |
| 形式 | PNG |

⚠️ **個人情報・案件情報の写り込みに注意。**
物件名・担当者名・ファイルパス・アカウント名などが写っていたら、
公開前に塗りつぶすか、ダミーに差し替えること。

## 記事側の書き方

記事の HTML にはあらかじめ `<figure class="tips-figure">` を仕込んであります。
**画像ファイルをここに置くだけで自動的に表示されます。**

画像がまだ無い間は、その figure は自動で非表示になる（`onerror` で自分を消す）ので、
「画像が表示できません」のアイコンが記事に出ることはありません。

→ つまり **記事を先に公開し、スクショは後から足していける**構成です。
