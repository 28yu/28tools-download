# tips/revit-cloud-model-recovery.html 用のスクリーンショット

記事の該当箇所に `<figure class="tips-figure">` を仕込み済みです。
下記のファイル名でこのフォルダに置けば、自動的に記事に表示されます。
（置くまでは非表示になるので、記事は今のままでも問題なく読めます）

| ファイル名 | 撮ってほしい画面 |
|---|---|
| `01-fatal-error-dialog.png` | 「重大なエラーが発生しました」等のエラーダイアログ |
| `02-save-recovery-file.png` | 修復ファイルの保存先を指定する画面 |
| `03-recovery-file-on-desktop.png` | デスクトップに保存された修復ファイル（.rvt）※ファイル名は塗りつぶし可 |
| `04-open-keep-changes.png` | クラウドモデルを開いたときの「変更を保持して開く」等の選択肢 |
| `05-no-sync-target.png` | 修復ファイル側で同期しようとしても同期先が無い状態 |
| `06-manage-links.png` | 「管理」→「リンクを管理」でリンクの状態を確認している画面 |
| `07-compare-schedules.png` | 修復ファイルと元モデルの集計表を並べて差分を確認している画面 |
| `08-sync-with-central.png` | 復旧後に「中央モデルと同期」を実行している画面 |

⚠️ 物件名・担当者名・アカウント名・ファイルパスの写り込みに注意。
