一般モデル化

3Dビューに見えている複数要素の形状を1つの一般モデルにまとめる

一般モデル化（複数要素の形状を1つにまとめる）

3Dビューに表示されているさまざまなカテゴリの要素（壁・床・柱・梁・一般モデル など）から形状を読み取り、一つの一般モデルのかたまりを作成する機能です。

出力形式は目的に応じて 2 種類から選べます。

  • ダイレクトシェイプ — このプロジェクトの中に直接かたまりを置く。手軽で速い。
  • 一般モデルファミリ (.rfa) — ファミリファイルを作って読み込む。他のモデルへ持ち出せる。

使いどころ

  • 複雑な躯体・設備の集合体を、軽い1つのオブジェクトにまとめて他部門へ渡したい
  • 作り込んだ部位を、編集されない固まりとして固定したい
  • 検討モデル一式を、1つの一般モデルとして別プロジェクトへ持ち出したい（ファミリ出力）

使い方

1. 3Dビューで範囲を決める

本機能は 3Dビュー専用 です。平面・断面ビューでは実行できません。

対象になるのは「そのビューに見えている要素」です。したがって実行前に、

  • セクションボックスで範囲を切る
  • ビューフィルタや要素の非表示で不要なものを消す

といった、いつもの3Dビューの操作で対象範囲を絞り込んでおきます。見えているものがそのまま対象になるので、画面で見えている状態＝処理される範囲です。

2. リボンから実行

リボン 28 Tools ＞ モデル ＞ 一般モデル化 をクリックします。

3. 対象カテゴリを選ぶ（左側）

ビュー内で見つかったカテゴリが、要素数つきで一覧表示されます（初期状態はすべてチェック）。不要なカテゴリのチェックを外して対象を絞り込みます。

カテゴリ名は Revit が返す実際の名前をそのまま表示します（Revit のバージョン・言語によって名前が異なる場合があるため、独自の翻訳は行いません）。

4. どの形式で作るか（①）

選択肢 内容
ダイレクトシェイプで作る プロジェクトの中に直接、形状のかたまりを置きます。ファイルは増えず、すぐ出来上がります。ただしファミリではないため、形を後から編集したり他のモデルへ持ち出したりはできません。
一般モデルファミリ (.rfa) で作る ファミリファイルを作成し、このプロジェクトへ読み込み・配置します。保存先はこのあと聞かれます。他のモデルでも使い回せ、ファミリエディタで編集できます。作成にはやや時間がかかります。

5. どうやって一つにまとめるか（②）

選択肢 内容 向いている場面
形はそのまま、要素だけ一つにする（おすすめ） 元の形状をそのまま持ったまま、Revit 上の「要素」としてだけ一つにまとめます。ブーリアン演算をしないので失敗しません。 まずはこれ。重なりを気にせず、とにかく1つにまとめたいとき
すべてつなげて一つの形にする 重なり・接触部分を溶かし合わせ、本当に単一の形状にします。断面がきれいにつながり、体積も正しくなります。 断面表示や体積が正確であることが重要なとき
くっついているものだけつなげる 触れ合っている要素どうしだけを溶かし合わせ、離れているものは別々の形のまま同じ一般モデルに入れます。 柱・梁など連続した部分だけ一体化したいとき

「つなげる」を選んだ場合、複雑な形状ではまれに結合できないことがあります。その場合でも形状を捨てずに元の形のまま残し、結果ダイアログでその個数をお知らせします（黙って形が欠けることはありません）。

6. 仕上がりの設定（③）

  • 材質 — 作成した一般モデル全体にこの材質を割り当てます。元の要素の材質は引き継ぎません。
  • 名前 — 作成する要素（ファミリ出力の場合はファミリ）の名前です。ファミリ出力では .rfa のファイル名の初期値にもなります。
  • 元になった要素をこのビューで非表示にする（初期 ON） — 元の要素は削除されません。このビューで見えなくなるだけなので、他のビューやモデルには影響しません。重ねて見比べたいときはチェックを外してください。

7. 実行

「一般モデルを作成」 をクリックします。ファミリ出力を選んだ場合は、続けて .rfa の保存先を指定します。

完了後、処理結果（作成した形状数・非表示にした要素数・対象外になった要素数など）がダイアログで表示されます。

仕様・注意事項

対象にならない要素

  • 立体形状（ソリッド）を持たない要素 — 通り芯、レベル、参照面、モデル線分など。処理時に自動で除外され、その個数が結果ダイアログに表示されます。
  • 注釈・ビュー固有の要素 — 寸法、タグ、詳細線分など。カテゴリ一覧にも表示されません。
  • リンクモデル（RVTリンク） — 現バージョンでは対象外です。カテゴリ一覧にも表示されません。リンク内の要素をまとめたい場合は、あらかじめリンクをバインド（結合）してからご利用ください。

材質の扱い

出力形式によって材質の適用方法が異なります。

出力形式 方法
一般モデルファミリ FreeFormElement の材質パラメータに直接設定します。確実に反映されます。
ダイレクトシェイプ Revit API にはダイレクトシェイプの材質を直接差し替える手段がないため、作成後に全面をペイントして単一材質にします。面数が極端に多い場合（20,000面超）は時間がかかるため材質の適用を見送り、その旨を結果ダイアログでお知らせします。形状は常に正確に作成されます。

ファミリテンプレートについて

ファミリ出力では、Revit の一般モデル用ファミリテンプレート（.rft）を使用します。Revit の設定フォルダから自動で探しますが、言語・地域によっては見つからないことがあります。その場合はファイル選択ダイアログが表示されるので、手動で .rft を指定してください。

位置

作成した一般モデルは、元の要素と同じ位置に重なって作成されます（ファミリ出力の場合も、形状の座標をそのまま持ち込んで原点に配置するため位置は変わりません）。

元に戻す

作成・非表示はすべて 1 つのトランザクションで行われるため、Ctrl + Z 一回で実行前の状態に戻せます。

トラブルシューティング

症状 原因・対処
「この機能は3Dビューで実行してください」と表示される 平面・断面・シート等で実行しています。3Dビューをアクティブにしてください。
「このビューに対象となるモデル要素が見つかりませんでした」 セクションボックスやフィルタで要素がすべて除外されています。ビューの表示状態を確認してください。
「立体形状を読み取れませんでした」 通り芯・レベルなど立体を持たない要素だけが選択されています。壁・床・柱などのカテゴリにチェックを入れてください。
つなげられなかった形状がある 複雑な形状同士のブーリアン演算に Revit が失敗した場合です。形状は元のまま残っているので欠落はありません。「形はそのまま、要素だけ一つにする」を選ぶと確実です。
「作成した一般モデルに形状が含まれていなかったため、処理を取り消しました」と表示される 何らかの理由で形状の作成に失敗しています。モデルは実行前の状態のままなので、そのまま再実行できます。メッセージ内の Revit のエラー文言と C:\temp\Tools28_debug.txt をご確認ください。
処理に時間がかかる 対象要素数・面数に比例します。3,000要素を超える場合は事前に確認ダイアログが出ます。セクションボックスで範囲を絞ると速くなります。

関連ログ

診断ログは C:\temp\Tools28_debug.txt に [CMD:GenericModelMerge] のタグで出力されます。
