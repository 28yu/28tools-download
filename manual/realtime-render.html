リアルタイムレンダリング

3DビューをGPUレイトレーシングで描画し、歩き回りながら確認・書き出し

リアルタイムレンダリング

Revit の 3Dビューを、そのままきれいな絵（レンダリング）で見ながら歩き回れる機能です。 光の通り道を 1 本ずつ計算する方式（レイトレーシング）で、影・映り込み・部屋の奥まで回り込む光を表現します。 Revit 以外のソフトは要りません。

描画は Revit とは別のウィンドウ（Tools28Render）で行います。万一こちらで問題が起きても Revit は止まりません。

必要なもの

  • GPU（グラフィックボード）: Vulkan に対応したもの（ここ数年の NVIDIA / AMD / Intel の GPU ならほぼ対応）
  • RT コア付きの GPU（NVIDIA RTX など）があると高速です。無い GPU でも、自動で予備の方式に切り替えて表示します（少し遅く、少し粗くなります）
  • ノートPCで「内蔵 GPU ＋ NVIDIA」の場合は、自動で NVIDIA の方を使います
  • GPU のドライバーは最新にしてください。リモートデスクトップ・仮想マシンでは GPU を使えず、起動できないことがあります

使い方

  1. Revit で 3Dビュー を開きます（透視ビュー・アイソメのどちらでも可）
  2. リボン 28 Tools ＞ レンダリング ＞ リアルタイムレンダリング をクリックします
  3. 別のウィンドウが開き、同じ視点で描画が始まります。止まっているとだんだんきれいになります

対象は「そのビューに見えているもの」です。セクションボックス・非表示・フィルタで見えなくしたものは描画されません。

操作

Revit の 3D ビューと同じ操作に加えて、キーボードで歩き回れます。ウィンドウの左下に操作の案内が出ます（右上の「×」で隠し、「?」で再表示）。

操作 内容
ホイール ズーム（カーソルの先の物に近づく）
ホイールを押してドラッグ 移動（パン）
Shift ＋ ホイールを押してドラッグ 回転（オービット）
ホイールをダブルクリック 全体表示
左ドラッグ その場で見回す
W A S D / 矢印キー 前後左右に歩く（Shift で速く）
Q / E 下がる / 上がる
+ / − 明るさ
R 最初の視点に戻る
P 今の視点を画像で保存
Esc 閉じる

ライブ同期（Revit の変更がすぐ反映）

描画ウィンドウを開いたまま Revit で作業すると、

  • 壁を動かす・マテリアルを変える などの変更が、数秒で描画ウィンドウに反映されます

視点は連動しません。描画ウィンドウと Revit のビューは、それぞれ自由に動かせます。 凡例・シート・注記・寸法など、描いている 3D ビューの見た目に関係ない編集では同期しません（Revit が重くならないように）。 平面・断面・立面・3D・集計表での編集は、形状や値が変わることがあるので同期します。

右上の 「同期中」ボタン をクリックすると同期を止められます（もう一度クリックで再開）。 大きなモデルでは、変更のたびに Revit が少し止まることがあります。気になるときは同期を止めてください。

書き出し（右上のボタン）

ボタンの下の小さな札（PNG / HTML / EXE）が、保存されるファイルの種類です。 ファイル名は「日付_ビュー名.拡張子」（例: 261016_3D 南東.png）が最初に入っています（保存先の画面で変えられます）。

ボタン 保存されるもの 使いどころ
画像（PNG） 今の視点の高画質な画像（PNG） 資料・プレゼンに貼る
360°（HTML） 見回せる 360°画像（HTML ＋ JPEG） HTML をブラウザで開くと、ドラッグで周りを見回せます。メールやチャットで送れば、相手は何もインストールせずに見られます
ビューア（EXE） 歩き回れるビューア（exe） Revit の無い PC でも、ダブルクリックで今と同じように歩き回れます
  • 画像・360°は保存に少し時間がかかります（進み具合が画面に出ます。Esc で中止）
  • ビューアの exe は署名の無いプログラムなので、受け取った PC で「Windows によって PC が保護されました」と出ることがあります。 その場合は 「詳細情報」→「実行」 で開けます。ビューアを開く PC にも Vulkan に対応した GPU が必要です

きれいに見せるコツ

マテリアル（外観タブ）

マテリアルの 「外観」タブ の内容を使います。

  • イメージ（テクスチャの画像）・色・反射率・粗さ・透明度・レリーフ パターン（凹凸）・自己発光 に対応しています
  • 画像が見つからないマテリアルは色だけで描画します。Autodesk のマテリアル ライブラリの画像と、 Revit のオプション「追加のレンダリング外観パス」に登録したフォルダ・プロジェクトのフォルダから画像を探します
  • ガラスは、外観の種類（ガラス・透明）か、マテリアル名に「ガラス / glass」があると透明として扱います
  • 金属は、外観の種類（金属）か、マテリアル名に「金属・スチール・アルミ・ステンレス」などがあると金属として扱います

照明器具

照明器具ファミリの 測光の設定（明るさ・色温度・配光・光源の形）を使って光らせます。

  • 実際の明るさに合わせているので、昼間は照明の効果は控えめです（本物と同じです）
  • 夜の様子を見るときは、ビューの 「太陽の設定」で夜の時刻 にしてから起動してください。照明が主役になります
  • 配光データ（IES ファイル）の形は使わず、下向きの半球として扱います

太陽

ビューの 「太陽の設定」（日時・場所）の太陽の向きを使います。真北の設定も反映されます。

うまくいかないとき

症状 対処
「Vulkan を使えません」「使える GPU が見つかりません」 GPU のドライバーを最新にしてください。リモートデスクトップでは使えないことがあります
模様（テクスチャ）が出ない 画像の場所が見つかっていない可能性があります。ログ C:\temp\Tools28_debug.txt に「テクスチャ画像が見つかりません」と出ます
動かすと粗く見える 止まると数秒できれいになります。RT コアの無い GPU では粗くなりやすいです
描画ウィンドウのログ %LOCALAPPDATA%\Tools28\Render\render.log（使った GPU・速さ・エラー）

できないこと（今後の予定）

  • 空の雲・時刻に合わせた空の色の変化
  • 配光データ（IES）の形
  • 草・人・車などの添景
