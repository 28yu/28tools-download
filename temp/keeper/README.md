# Keeper（作り直し版）

一定間隔（60秒）で Shift キーを押して、パソコンが離席中・スリープにならないようにする常駐ツール。
元の `temp/keeper.exe`（Python 製・約19MB）と同じ動きを C# で作り直した。

| | 元の版 | この版 |
|--|--|--|
| サイズ | 約19MB | 約18KB |
| 作り方 | Python（PyInstaller で本体ごと同梱） | C#（Windows 10/11 に入っている .NET Framework 4.8 を使う） |
| 夜間の停止 | なし | **あり（既定 21:00〜07:00・設定で変更／オフ可）** |

## 使い方
- `keeper.exe` をダブルクリック → 画面右下（タスクトレイ）に緑の丸のアイコンが出る
- アイコンを右クリック: 「設定を開く」「有効 / 無効」「終了」（ダブルクリックでも設定が開く）
- アイコンにマウスを乗せると状態が出る（`Keeper [ON]` / `Keeper [ON・夜間は停止中]` / `Keeper [OFF]`）
- 設定は元の版と同じく、終了すると初期値に戻る

## ビルド（Claude の開発環境）
```bash
dotnet build -c Release -o out   # out/keeper.exe ができる
```
