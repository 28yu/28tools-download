AI議事録 自動作成

打合せ音声と資料から、AI が議事録を自動作成 — 文字起こしはブラウザ完結。高精度版はあなた自身の無料 Gemini API キーを利用します。

● 録音データは端末内で処理。AI の生成結果は必ずご確認ください。
🔒 プライバシーについて — 音声の文字起こし（簡易版）と議事録の図解化はあなたのブラウザ内のみで行われ、サーバへ送信されません。
高精度版で「Gemini」を使う場合は、音声・資料がGoogle のサーバへ送信されます。 無料枠の API は入力データが品質改善に利用される可能性があるため、機密性の高い打合せでは送信内容にご注意ください。
⚠️ 自動作成は完璧ではありません — 音声の聞き取りや内容の分類には誤りが含まれます。 出力後にプレビュー上で内容を確認・編集してから保存してください。図面の寸法・記号の正確な転記は保証対象外です。

打合せを録音するだけ。停止すると自動で議事録ができます。

高精度版には無料の Gemini API キーが必要です（初回のみ）。
分割セグメント

※ 通常録音では録音データは端末に保存されません（ブラウザのメモリ上で処理）。長時間モードでは分割した音声を選んだフォルダ／ダウンロードに保存します。高精度版では生成時に Google へ送信されます。

設定
🎙️ 入力レベル — 話すとメーターが動けばOK

打合せの前に、音が拾えているか確認できます。テスト中は録音されません。

キーはこの端末のブラウザにのみ保存され、28tools のサーバへは送られません。 取得方法 → Google AI Studio（無料）

録音を続けたまま指定間隔ごとに音声を保存し、各区間を高精度版(Gemini)で自動的に議事録化して1本に結合します。開始時に保存先フォルダを選択します（対応ブラウザのみ・非対応時はダウンロード保存）。高精度版の API キーが必要です。

長時間モードで分割した音声の保存先です。録音の開始時に選ぶこともできます。

出力
📋 議事録

議事録の要点から、共有・表紙用の 1 枚絵を Gemini の画像モデルで作成します。 高精度版と同じ API キーを使います（画像の無料枠は議事録本体とは別枠です）。

⚠️ 画像内の文字は AI が「描いた」ものなので、誤字や崩れが起こります。正式な記録は議事録本体（テキスト）をご利用ください。 高品質 Pro は Google 側で従量課金が発生します。
